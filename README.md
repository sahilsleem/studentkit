# StudentKit

### Free Student Tools for Smarter Learning

StudentKit is a collection of free tools for studying, calculations, assessments, and everyday academic tasks.

Instead of jumping between dozens of websites for a calculator, converter, reasoning test, or quick study utility, StudentKit brings practical student tools together in one fast, simple interface.

**Website:** https://studentkit.in

---

## What is StudentKit?

StudentKit is built around a simple idea:

**Students should be able to open a tool, solve the problem, and move on.**

The platform provides free browser-based tools covering academic calculations, science and engineering utilities, assessments, cognitive training, measurement conversion, and other common student needs.

There is no unnecessary account wall or complicated workflow.

## Tests & Assessments

StudentKit also includes interactive assessments for reasoning and cognitive skills.

Current assessment categories include:

* IQ & reasoning
* Logical reasoning
* Numerical reasoning
* Verbal reasoning
* Spatial reasoning
* Memory

These are designed for practice, self-evaluation, and skill-building.

*(Note: These are not professional psychological or medical assessments.)*

---

## Anti-Brainrot

StudentKit includes a dedicated **Anti-Brainrot** training section.

It provides short cognitive exercises designed around:

* Mental arithmetic
* Working memory
* Sustained attention
* Visual discrimination
* Sequence recall
* Mental manipulation
* Quantitative reasoning

The goal is simple:

**Train your ability to focus instead of endlessly scrolling.**

Training progress is stored locally in the browser where applicable.

---

## Privacy & Simplicity

StudentKit is designed to work primarily in the browser.

Most calculations and exercises are processed entirely locally on your device rather than uploaded to a remote server. StudentKit does not require unnecessary account creation just to use its core tools.

---

## Design Philosophy

### Tool first
Open a tool and use it immediately.

### Free
Core StudentKit tools are available without a paywall.

### Fast
The interface is designed for quick use on both desktop and mobile devices.

### Simple
No unnecessary dashboards, complicated workflows, or friction between the student and the tool.

### Practical
Every tool should solve an actual student problem.

## Technology

StudentKit is built with a modern web stack to ensure speed and reliability:

* **Astro** - Static site generation and framework
* **TypeScript / JavaScript** - Application logic
* **Tailwind CSS** - Styling
* **Math.js** - Advanced mathematical computations
* **GSAP** - Animations

---

## Running Locally

To run StudentKit locally, clone the repository and run the following commands:

Install dependencies:
```bash
npm install
```

Start the development server:
```bash
npm run dev
```

Create a production build:
```bash
npm run build
```

---

## Project Structure

* `src/` - The main application source code.
  * `pages/` - Astro page routes, including the main directory and tool views.
  * `components/` - Reusable Astro and UI components.
  * `layouts/` - Shared page layouts and wrappers.
  * `data/` - Static data structures, such as the tool registry and categorized directories.
* `public/` - Static assets, icons, and configuration files served at the root.
